# Antares Framework

A modern, lightweight PHP framework designed for building fast and scalable APIs.

## Get Started

- [Introduction](/getting-started/introduction/)
- [Installation](/getting-started/installation/)
- [Quick Start](/getting-started/quick-start/)

## Features

- **Dependency Injection** - Autowiring container with constructor injection, interface bindings, singletons, and per-request scoped instances.
- **Attribute Routing** - Define routes using PHP 8 attributes directly on controller methods.
- **Validation & DTOs** - Type-safe request validation with automatic DTO hydration.
- **Response DTOs & OpenAPI** - Typed responses, serialized to JSON, with an OpenAPI spec generated from the same classes.
- **PSR-7** - Requests and responses are PSR-7 messages, with a simple middleware pipeline around them.

## Quick Example

```php
use Antares\Router\Attributes\Get;

class UserController
{
    #[Get('/users/{id}')]
    public function show(int $id): array
    {
        return ['id' => $id, 'name' => 'John'];
    }
}
```
